# Prompts ChatGPT pour les scènes

Une image par prompt, à coller tel quel dans ChatGPT. Même modèle de phrase pour
toutes les scènes, pour garder le même style (celui des scènes Dinosaures).

Règles qui comptent pour le jeu :
- chaque objet de la liste doit apparaître **une seule fois** (sinon il est écarté) ;
- pas de texte, de lettres ni de chiffres ;
- des objets petits, de la même taille, à moitié cachés.

Ensuite : envoyer l'image dans la conversation avec Claude, qui repère et vérifie chaque objet.

---
